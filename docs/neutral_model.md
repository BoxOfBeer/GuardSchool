# Концептуальная модель (surface vs core)

GuardSchool вырос из **школьной** предметной области; это **база данных и API**, не обязательно язык интерфейса.

## Два слоя

| Слой | Роль | Примеры |
|------|------|---------|
| **Core (schema)** | Стабильные id, файлы, поля JSON | `lesson`, `class_key`, `bell_schedules.json`, `school_news` |
| **Surface (UI / импорт)** | То, что видит администратор | слот / сигнал / группа; колонки Excel «Группа», «Слот1» |

**Правило:** переименование core — только при мажорной миграции; surface дочищается постепенно (`static/locales`, `gs_bell_strings`, алиасы Excel).

## Словарь аналогов

| Core (поле / файл) | Surface (RU) | Surface (EN) | Другие сценарии |
|--------------------|--------------|--------------|-----------------|
| `schedule` / строки по дате | Расписание | Schedule | Смены, дежурства |
| `full_schedule` / weekday | Недельная сетка | Weekly grid | Постоянный план смен |
| `lesson` (номер слота) | Слот | Slot | Интервал приёма, смена |
| `bell` / `entries` | Сигнал | Signal | Перерыв, гong, смена |
| `class_key` | Группа | Group | Бригада, поток, кабинет |
| `school_news` | Новости | News | Лента организации |
| tenant / школа (SaaS) | Организация | Organization | Цех, филиал, кампус |

## Excel

Поддерживаются **школьные и нейтральные заголовки** (см. `gs_excel_import.py`):

| Назначение | Школа (как было) | Нейтральные алиасы |
|------------|------------------|---------------------|
| Дата | `Дата` | `Date` |
| Группа | `Класс` | `Группа`, `Class`, `Group` |
| Слот N | `Урок1` … | `Слот1`, `Slot1`, `Lesson1` … |
| День недели | `День недели` | `Weekday`, `Day of week` |

Внутри JSON по-прежнему `class_key`, `lessons[].index` — без переименования.

## Инструменты

- `python tools/neutralize_terminology.py` — массовая замена в `static/locales/*.json` (значения, не ключи)
- `python tools/check_locales.py --check-tv --warn-terms` — паритет ru/en, sync `tv-locales.js`, предупреждения о «школьных» словах

## Позиционирование

- **Школа** — главный и исторически первый сценарий (README, примеры Excel).
- **Продукт** — «время + структурированные данные на экранах»; школа не единственный потребитель surface-словаря.
