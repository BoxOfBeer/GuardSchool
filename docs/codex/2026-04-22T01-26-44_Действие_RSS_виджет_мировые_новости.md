# Цель
Реализовать виджет «Мировые новости» (RSS): настройка источников в админке, сервис загрузки/кэширования RSS, выдача 5 последних новостей в payload экрана, отображение заголовка/источника/QR.

# Контекст
- Входные данные: постановка по виджету `rss_news`, раздел «RSS источники», кэш 30–60 минут, хранение полей `title/link/source/published_at`.
- Ограничения: не ломать существующие виджеты, добавить только нужную UI-связку, бизнес-логика загрузки RSS — на backend.
- Ожидаемый артефакт: рабочий end-to-end поток (админка -> config -> backend cache -> TV/preview widget).

# План
1. Добавить backend-сервис RSS с санитайзингом источников, TTL-кэшем и нормализацией новостей.
2. Встроить RSS-поля в конфиг и payload API.
3. Добавить тип `rss_news` в backend/frontend словари и настройки виджетов.
4. Добавить UI-блок «RSS источники» в настройках программы.
5. Проверить линтер/компиляцию и зафиксировать результат.

# Решения/обоснования
- QR реализован как внешний PNG-генератор по URL новости (`api.qrserver.com`), чтобы не тащить новый JS/Python пакет и быстро получить кросс-браузерный результат.
- TTL обновления зафиксирован на уровне 30–60 минут (конфиг), default 45 минут.
- Данные RSS не пишутся в основной config.json как новости: только источники и интервал; сами новости — в отдельный кэш-файл.

# Риски
- Внешний QR-сервис может быть недоступен в закрытом контуре сети.
- Некоторые RSS-фиды могут иметь нестандартный XML (частично нивелировано поддержкой RSS/Atom и мягкой деградацией).
- При недоступности источников виджет показывает «Нет новостей».
