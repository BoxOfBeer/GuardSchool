# Цель
Реализовать виджет «Новости школы» и раздел админки для CRUD новостей, включая вывод на экран ТВ и переход по QR на полную страницу новости.

# Контекст
- Входные данные: задача №2 (виджет новостей школы), требование на 3 активные новости с автопереключением 10–15 сек.
- Ограничения: проект использует FastAPI + статический фронтенд без отдельной БД-миграционной подсистемы в текущем репозитории.
- Ожидаемый артефакт: backend API + хранение данных + UI в админке + рендер виджета на экране.

# Решения/обоснования
- Хранение реализовано в `data/school_news.json` для совместимости с текущей файловой моделью проекта.
- Для QR использован внешний генератор изображения (`api.qrserver.com`) без добавления новых зависимостей в backend.
- Для полного текста новости сделана отдельная публичная страница `/school-news/{id}`.

# Риски
- Внешний QR-сервис требует интернет-доступа; в изолированных сетях QR-изображение может не загрузиться.
- Контент новости хранится как HTML-строка; при вводе нужно соблюдать редакторскую дисциплину.
