Python backend-пакет GuardSchool (FastAPI, SaaS/локальные режимы, импорт/экспорт, ТВ-авторизация).
Изменения в бизнес-логике вносятся здесь, UI-файлы только связывают API.
Контентные API (например, school_news) должны санитизировать HTML и отдавать публично только активные сущности.
Отдельные сервисы интеграций (например RSS) выносить в модули `gs_*`, а в `app.py` оставлять только связку API/оркестрацию.
