Уроки и Excel

Справка: колонки, import, приоритет данных

По датам — «Дата», «Класс», «Урок1»… или data/import/schedule.xlsx. По неделе — «День недели», «Класс», уроки; full_schedule.xlsx в import. Образец — отличие от полного → подсветка на ТВ. Приоритет: ручная замена → образец → датированное/полное.

Импорт из Excel

Файлы в data/import подхватываются автоматически; здесь — ручная загрузка.

Архив недели (ZIP)

В архиве: full_schedule.json, schedule_sample.json, шаблон full_schedule_sample.xlsx, README.txt. Достаточно хотя бы одного JSON при импорте.

Состояние данных

Ручные замены

Замена на конкретную дату для класса и номера урока.

Звонки

Редактор шаблона и интервалов развернуть: звуки, строки по урокам, сохранение

Шаблон и даты

Если указать последний урок (например 5), звонки начала/конца для больших номеров в шаблоне не звучат — чтобы после 5-го не было «начала 6-го».

Автовыбор шаблона по дням недели

В поле «Урок»: только цифры (1–8…) — связь с колонками Excel; текст без одних цифр — внеурочный интервал (пятиминутка, линейка…). На экране без цифр в фразе минуты подставляются автоматически.

Предпросмотр шаблона

Те же данные, что на ТВ: расписание, звонки, праздники (сервер считает по полям текущего экрана, даже до «Сохранить»).

Блоки можно перетаскивать мышкой. `Shift` + перетаскивание изменяет размер.

Сетка экрана: `32x26`.

Изменения программы

Здесь только выпуски программы (номер версии в записи). Сохранения расписания и настроек в этот список не попадают.

Звук ПК

На ТВ — звук из браузера. На ПК — ffmpeg (wasapi) или ffplay из той же папки. Сохраните конфиг после правок.

Конец урока — время «конец» в строке расписания и звук конца (или дефолт шаблона).

Статус загружается…

Без галочки фоновые звонки на ПК не идут.

Громкость музыки перемен — ползунок в плеере справа; громкость звонков — поле слева в таблице настроек.

Пустой пункт — первый экран в списке.

Как bell_audio.trigger_sec_window для ТВ. Быстрый тест — Настройки → Рупор / ТВ.

Настройки программы

Язык, время и пояс

Добавляется к «настенному» времени на ТВ (если часы устройства неточны). Диапазон ±720 мин.

Облако / гибрид

Локальный сервер может подтягивать ZIP с облака по токену. ТВ: параметры URL gs_primary_base, gs_fallback_base, gs_tv_token, gs_poll_timeout_sec.

Виджеты в списке под «Виджеты»

Снятая галочка скрывает тип только в списке под заголовком «Виджеты» (кнопка «Настроить»). На ТВ и в сетке предпросмотра без изменений. Чтобы настроить скрытый блок — отметьте тип снова.

Подключение ТВ (SaaS)

Сгенерируйте короткий код школы, задайте PIN (4–12 цифр) и используйте ссылки для экранов: /t/<код>/<экран>.
