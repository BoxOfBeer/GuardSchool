Модульная логика админки (state, виджеты, предпросмотр, импорт данных).
Здесь меняются обработчики UI и связывание с API без переноса бизнес-правил в шаблоны.
Модули админки (JS): состояние, API-вызовы, рендер форм и предпросмотра.
Изменения UI должны только связывать backend-контракты и не переносить бизнес-логику в клиент.
